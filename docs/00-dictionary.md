# พจนานุกรมชื่อกลาง (Central Naming Dictionary)

Merged from all four specs. All names kept exactly as written in the specs.
Last updated: 11 Nov 2026 · Owner changes and additions per docs/05-decisions.md

## วิธีใช้
- ใช้ชื่อในคอลัมน์ "ชื่อ" เท่านั้น ในโค้ด, คอมเมนต์, และฐานข้อมูล
- ถ้าต้องแปลงเป็น identifier ภาษาอังกฤษ ให้ทับศัพท์อย่างสม่ำเสมอและเก็บ mapping ใน `lib/dict-transliteration.ts`
- ชื่อใหม่ต้องได้รับอนุมัติจากทีมก่อนใช้ในโค้ด
